# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Overview
This project predicts the presence of heart disease using clinical data and multiple machine learning algorithms. The best-performing model achieved **94% accuracy**.

## 🚀 Tech Stack
- Python
- Scikit-learn
- Pandas
- NumPy
- Matplotlib / Seaborn

## ⚙️ Workflow
- Data preprocessing and cleaning  
- Feature selection  
- Model training (Logistic Regression, SVM, Decision Tree)  
- Model evaluation using confusion matrix and accuracy metrics  
- Data visualization and correlation analysis  

## 📊 Results
- Achieved **94% accuracy**
- Evaluated using confusion matrix and classification metrics  

## 🔮 Future Improvements
- Hyperparameter tuning  
- Cross-validation  
- Deployment using Flask
